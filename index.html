開始之前

準備這幾樣就好

  • iPhoneiOS 17.4 以上，已設定解鎖密碼。新系統的實際連線支援以 App 狀態為準。
  • 電腦與 USB 線Mac 或 Windows，使用可傳輸資料的線材。
  • Apple 帳號用於簽署與安裝；準備密碼及雙重認證驗證碼。
  • 可用的 Wi-Fi第一次連線需下載開發者映像；建議先用 Wi-Fi 完成。
Google 帳號是選用的。用來備份個人收藏與已拉紀錄；安裝 App 使用的是 Apple 帳號。

確認是上方官方下載的檔案後，到「系統設定 → 隱私權與安全性」，找到被阻擋的 App，依畫面選「強制打開／仍要打開」。如果沒有這個選項，請查看 Apple 開啟 App 說明。

03

電腦安裝 · 手機確認

把 RingoFly 裝進手機

  1. 用 USB 連接 iPhone 與電腦，解鎖手機。出現「信任這部電腦」時按信任，並輸入解鎖密碼。
  2. 在電腦開啟 iloader，登入自己的 Apple 帳號，依提示輸入驗證碼。
  3. 在裝置清單選擇這支 iPhone。
  4. 點下方「前往 GitHub 最新版本」，用受邀的 GitHub 帳號登入。在版本頁的 Assets／資產 找到 .ipa 安裝檔並下載；回到 iloader 按 Import IPA／匯入 IPA，選擇檔案並等待安裝完成。
  5. 在 iPhone 前往設定 → 一般 → VPN 與裝置管理，點自己的開發者帳號，依畫面完成「信任」或「允許並重新啟動」。
  6. 前往設定 → 隱私權與安全性 → 開發者模式，開啟後依提示重新啟動，解鎖並確認啟用。
  7. 回到主畫面，開啟 RingoFly。

前往 GitHub 最新版本

私人專案：請先註冊 GitHub 帳號，將帳號名稱提供給 Ringo；收到並接受邀請後，登入下載。下載 Assets 內的 .ipa；「Source code」是原始碼，不是手機安裝檔。

IPA 需要用 iloader 安裝。直接點檔案不會安裝。已經裝過 RingoFly 的使用者，請用原 Apple 帳號覆蓋安裝，保留相同 App 識別，不要先刪除。

04

只需要這支手機的配對檔

匯出配對檔，再匯入 RingoFly

  1. iPhone 保持 USB 連接、解鎖。在 iloader 選擇這支手機。
  2. 按 Manage Pairing File／管理配對檔。
  3. 選 Export／匯出（部分版本顯示「Export (Not Recommended)」），確認匯出，將檔案存成 pairingFile.plist。
  4. Mac 可用 AirDrop 傳給自己的 iPhone；Windows 可存入自己的私人 iCloud Drive。收到後存到手機的「檔案」App。
  5. 開啟 RingoFly，按匯入配對檔案，選取剛剛存好的檔案。若已進入地圖，可到設定內更換配對檔。
為什麼用匯出？iloader 的自動放置清單目前未包含 RingoFly，所以採用手動匯入。配對檔屬於這支手機，不能用別人的檔案；請勿放在群組或共享資料夾。

按鈕及匯出方式：iloader 官方介面與配對檔實作。

✓完成時：RingoFly 顯示「配對檔案已匯入」。

  3. 首次下載開發者映像 DDI 時保持網路暢通；下載及掛載完成前不要反覆按重試。
  4. 看到下方三項完成，即可進入地圖。
  5. 若系統詢問定位權限，先允許「使用 App 期間」。需要背景維持時，再依 App 提示調整權限。

06

先完成一次定位與恢復

開始使用 RingoFly

第一次試用

  1. 在地圖搜尋地名，或輸入座標，例如 25.0330, 121.5654。
  2. 選好位置，按首頁的開始模擬定位。
  3. 看到定位建立成功後，到 Apple 地圖或需要定位的 App 重新整理，確認位置。
  4. 要回到真實位置，按首頁右側設定齒輪下方的返回箭頭 ↶，等待恢復定位。

拖動地圖只是選點。暫停路線或退出搖桿會停在模擬位置；回到真實位置請用返回箭頭。

搖桿

上北、下南、左西、右東。放開停住；退出仍保持目前位置。

GPX／KML 路線檔怎麼使用？
  1. 將 GPX 或 KML 存進 iPhone 的「檔案」App。
  2. 點下方 GPX／KML，選擇檔案。
  3. 確認路線預覽，設定速度與圈數，再開始移動；也可先儲存成常用路線。

KML 需包含路線資料（LineString 或 Track）；只有地標的檔案不適用。KMZ 請先解壓取得 KML。

分類與排序在哪裡？

收藏與金盆清單頂部可篩選分類，並選新到舊、舊到新、名稱首字、距離近到遠或原清單順序。距離排序以目前位置計算，必要時更新目前位置。

右上 ⋯ 可管理分類與調整順序。金盆可按活動／地點分組；已拉過會排在後面，尚未開始的活動會標示未開始。

批次匯入收藏在哪裡？

收藏右上 ⋯ → 批次匯入，選整理好的 UTF-8 CSV 或支援的 JSON，確認預覽後匯入。Excel 請另存「CSV UTF-8」，不直接匯入 XLSX。

第一次匯入先用「合併」保留現有清單。更新已有地點請確認匯入模式；選「取代」前先保留完整檔案。

07

需要時再設定

共享清單與個人備份

查看共享收藏與金盆

  1. 向維護者取得同步服務網址與個人存取碼。
  2. 首頁右上設定 → Cloudflare 共享同步，填入網址與存取碼，按驗證並儲存。
  3. 成功後，從「收藏 → 共享收藏」或下方「金盆」查看清單。需要最新版本時按「立即檢查更新」。

共享清單僅由管理者維護。其他使用者可查看與使用，沒有新增、編輯、刪除、匯出或發布共享清單的選項。你勾選的已拉紀錄屬於個人，不會發布給其他人。

管理者：如何延長接收者的存取碼？
  1. 到「設定 → Cloudflare 共享同步 → 管理接收者權限」。
  2. 找到接收者，按「延長期限」，選 30、90 或 365 天。
  3. 確認「期限已延長」訊息與新的有效日期。原存取碼不變，對方不用重新輸入。

未到期的從原到期日延長；已到期的從今天起算。已撤銷的碼不能延長，需另建新碼。接收者右側 ⋯ 可編輯名稱；展開「已撤銷」可刪除紀錄，不影響個人備份。這些管理選項只有管理者可見。

用 Google 備份，換手機能接續

  1. 首頁設定 → Google 帳號與個人備份。
  2. 確認服務網址；新帳號填維護者提供的邀請碼。已設定共享存取碼時，App 可使用同一個碼。
  3. 按使用 Google 帳號登入，完成帳號授權。
  4. 原手機已有資料時，按加入手機原本的資料，確認合併。
  5. 等待顯示個人收藏與已拉紀錄已同步，確認上次同步時間。
  6. 換手機完成安裝、建立新手機的配對檔後，用同一 Google 帳號登入讀取已備份資料。
未登入也能使用。資料保存在原手機。Google 備份包含個人收藏、收藏分類順序及已拉紀錄；已存路線目前不包含在這份備份。
帳號、配對檔與備份怎麼保護？

Apple 密碼與驗證碼只在官方安裝工具輸入，不需提供給 Ringo。配對檔只交給自己的手機使用；匯入後，請將「檔案」App 或電腦裡不需要的副本移除。

同步網址與個人存取碼請向 Ringo 取得，勿改用陌生人提供的網址；存取碼只分享給本人。撤銷會停止後續共享同步，已下載的離線清單與既有 Google 個人備份仍可能保留。

Google 用於確認身分，雲端保存帳號識別、電子郵件、收藏名稱與座標、分類及已拉時間；不會備份 Apple 密碼、配對檔或持續的即時定位。資料依帳號分隔，服務維護者仍具資料庫管理權限；建議不要把私密地點存入雲端備份。

兩種方式，自行選擇

續期與更新 App

免費 Apple 帳號的簽署有效期是七天。續期會重新簽署；更新則是安裝新版 IPA。

選擇你的續期方式
方式如何續期適合誰
iloader接電腦，重新匯入 IPA 覆蓋安裝想少裝一個工具
SideStore（選用）手機接 Wi-Fi、開 VPN，按重新整理想直接在手機續期

查看新版與更新日誌

RingoFly 設定 → 版本與更新可查看目前安裝版本與線上最新版本，按更新日誌查看功能與修正。有新版時按「前往 GitHub 最新版本」，下載 IPA 後覆蓋安裝。

方式 A：繼續用 iloader

  1. 到期前用 USB 連接 iPhone，開啟 iloader。
  2. 登入原本的 Apple 帳號，選擇這支手機。
  3. 按「Import IPA」，選 RingoFly IPA，保持相同 App 識別覆蓋安裝。
保留資料的關鍵：不要先刪除 App。更新前先完成個人備份；路線另行保留。若帳號或 App 識別改變，可能會被當成另一個 App。
選用工具

方式 B：安裝 SideStore，用手機續期

需要第一次用電腦安裝；之後可以在手機重新整理簽署。仍須七天續期，背景續期可能失敗，請每週確認剩餘天數。

一次性的安裝與轉入

  1. 先備份 RingoFly 的個人資料，保留已安裝的 App。
  2. 用 USB 連接 iPhone，在 iloader 登入原簽署 Apple 帳號並選擇這支手機。
  3. 選 Install SideStore (Stable)，等待完成。配對檔會由 iloader 自動放入 SideStore。
  4. 依手機提示信任開發者帳號、啟用開發者模式（前面已完成就跳過）。
  5. 連上 Wi-Fi，開啟 LocalDevVPN，確認已連線。
  6. 開啟 SideStore，登入同一 Apple 帳號。
  7. 在 My Apps／我的 App，先點 SideStore 旁的剩餘天數，完成第一次重新整理。需要重新啟動時稍等，再開啟。
  8. 把 RingoFly IPA 存到 iPhone 的「檔案」，在 SideStore 的 My Apps 點 ＋，選擇 IPA 安裝。保持原帳號與相同 App 識別，覆蓋現有 RingoFly。
  9. 重新開啟 RingoFly，確認收藏與路線仍在，且 SideStore 的 My Apps 已列出 RingoFly。

每週手機續期

  1. 連上 Wi-Fi，開啟 LocalDevVPN。
  2. 開啟 SideStore → My Apps，按 Refresh All／全部重新整理，或逐一點剩餘天數。
  3. 確認SideStore 與 RingoFly都續期成功，剩餘天數重新增加。
是否安裝由你決定。SideStore 是開源工具，不需越獄，但需要 Apple 帳號與配對資料。只用官方來源、保留雙重認證；不要分享配對檔。免費帳號的三個側載 App 名額包含 SideStore 本身。

常見問題

GitHub 顯示 404，或找不到 IPA？

此專案保留私人。請先註冊 GitHub 帳號，將帳號名稱提供給 Ringo，收到並接受專案邀請後，登入受邀帳號。進入最新版本頁後，在 Assets 找 .ipa；若維護者尚未發布版本或上傳 IPA，請等維護者完成發布。

iloader 找不到 iPhone

解鎖 iPhone、確認已信任電腦，拔插 USB，改用可傳資料的線及另一個 USB 埠。Windows 先確認 iTunes 能看見手機；仍無法辨識時，依官方準備說明改試 Apple Devices。

App 顯示不受信任，或找不到開發者模式

先完成 IPA 安裝，再到「設定 → 一般 → VPN 與裝置管理」信任自己的開發者帳號。之後查看「隱私權與安全性 → 開發者模式」，依提示重啟並確認啟用。

匯入配對檔失敗

用最新版 iloader、USB 連接並解鎖同一支 iPhone，重新匯出配對檔後匯入。請選完整的 PLIST 檔，不要改內容或使用其他手機的檔案。系統更新、重置或檔案失效後，可能需重新配對。

三項準備一直無法完成

確認 Wi-Fi 有網路、LocalDevVPN 已連線。第一次 DDI 下載需要時間，保持 App 開啟；若顯示失敗，再按「重試連線」。其他 VPN 可能干擾，先中斷再用 LocalDevVPN。

按恢復後，地圖還停在模擬位置

先等清除指令完成，再到 Apple 地圖按目前位置確認。收到新的真實定位可能需要等待；若 RingoFly 顯示尚未確認恢復，保持 VPN 連線並依提示重試。畫面停止不等於 GPS 已恢復。

七天後 App 打不開，怎麼辦？

先保留 App，使用原帳號與相同 App 識別重新簽署覆蓋安裝。若 SideStore 本身也過期，接回電腦，用 iloader 覆蓋安裝 SideStore，再完成重新整理與 RingoFly 續期。

SideStore 會不會自動幫我續期？

有背景重新整理機制，但會受網路、VPN 與 iOS 背景排程影響。每週主動打開 My Apps，看 SideStore 與 RingoFly 的剩餘天數，才知道有沒有續期成功。

SideStore 安全嗎？

官方提供公開原始碼，不需越獄。開源不等於零風險；它需要處理 Apple 登入與簽署資料。只從官方下載，保留雙重認證，不分享配對檔。官方 FAQ 亦說明舊版 Anisette 登入驗證服務可能造成帳號鎖定；遇到問題依官方指引處理。

查看 SideStore 官方 FAQ
Google 登入成功，但原收藏怎麼不見了？

登入後會切到帳號的私人資料。到「Google 帳號與個人備份」按「加入手機原本的資料」合併，再等同步成功。未登入時的原資料仍保留在手機，登出可以回到那份資料。

換手機後，為什麼沒有舊資料？

原手機須先登入 Google、加入手機原本的資料，並完成雲端同步。新手機使用同一 Google 帳號；配對檔需要為新手機另外建立。已存路線目前不包含在 Google 個人備份。
